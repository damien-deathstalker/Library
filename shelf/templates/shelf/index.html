{% comment %} One card, reused for every book. A real rather than a div with a high z-index, because the browser then puts it in the top layer, keeps Escape and the focus ring working, and returns focus to the cover it was opened from -- all of which is a page of script if it is built by hand, and none of which can be got subtly wrong. It is a shell: the shape never changes, so it is written once. Only the body is built per book. The link out of every slot still points at the book page. Opening the card is something added on top of that page, not a replacement for it, so a reader without script, a crawler, and a shared link all still get the book -- and an address left in the bar still reaches the book, not a card over the shelf, because a card is a moment and a page is a place. {% endcomment %}

Hello, and welcome. I honestly don't know how you found your way here, but I'm glad you did.

I have this dream: I want to be an author. And the one thing any good author needs is an audience. So here you are. Everything I'm writing is on this shelf, free to read, with new chapters going up as I finish them.

Read as far as you like, then tell me what you made of it. The comments under each chapter come straight to me, and I do read them.

Some of these are unfinished. Secular work is demanding — a man's gotta eat, you know. I'll put out a new chapter at least every two weeks for whichever book you're furthest through.
